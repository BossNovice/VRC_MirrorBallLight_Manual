2. ライブプリセット

表示名 初期値 効果
ライブプリセットを使用 OFF Preset配列と切替処理を有効にします。
開始時に選択中プリセットを適用 ON Start時に現在の同期番号を適用します。
プリセットの動作範囲 グローバル ローカルは自分だけ、グローバルは選択番号と開始時刻を同期します。
プリセット一覧 配列 適用順。番号は0から始まります。
選択プリセット番号（0から） 0 ApplySelectedPresetで適用する番号です。
クロスフェード時間（秒） 0.8 0で即時、値を増やすと演出設定を補間します。
クロスフェード曲線 滑らか 線形／滑らか／ゆっくり開始／ゆっくり終了です。

プリセットを作る

  1. Controllerで「新しいプリセットを追加」を押します。子GameObjectとPresetコンポーネントが追加されます。
  2. Controller側で基準となる見た目を作ります。
  3. 「選択プリセット番号」を保存先番号へ合わせます。
  4. 「現在値を選択プリセットへ保存」を押します。
  5. 必要数だけ繰り返し、「一覧を子から自動検出」で配列を整理します。
  6. 「選択番号をプレビュー適用」でEdit Modeの見た目を確認します。

Presetに保存される項目

Presetは次の演出値を保持します。Controllerの必須参照、電源範囲、最適化設定などは切り替えません。

分類 保存される項目
回転・反射 回転速度、基本色、反射光明るさ、通常面／透過面明るさ、透過Alpha
カラー ランダム色、彩度、色相速度、色明滅
AudioLink 用途別帯域、明るさ／サイズ／色の増加、履歴モード／遅延
投影Cookie 使用状態、方式、2D／Cube Texture、強さ、色、Tiling、Offset、回転
光点 タイル数、サイズ、ぼかし、比率、形状、単一Texture、アトラス設定、点灯割合、切替、明滅
距離 フェード開始／終了、減衰曲線

実行中の切替イベント

Custom Event名 動作
NextPreset 次のPresetへ移動し、末尾から先頭へ循環します。
PreviousPreset 前のPresetへ移動し、先頭から末尾へ循環します。
ApplySelectedPreset 「選択プリセット番号」をクロスフェード適用します。
ApplySelectedPresetImmediately 同番号を補間なしで即時適用します。
ReloadCurrentPreset 現在番号を再読込します。
TogglePower／TurnOn／TurnOff 電源UI用イベントです。
UseStandardLightingVariant 通常版本体へ切り替えます。
UseIntegratedLightingVariant 連携版本体へ切り替えます。

Unity UI Buttonへ接続

  1. ButtonのOn ClickへController GameObjectを登録します。
  2. UdonBehaviour.SendCustomEvent(string)を選びます。
  3. 文字列へ上表のEvent名を正確に入力します。
大文字・小文字を含め完全一致が必要です。グローバル切替では操作したPlayerがOwnershipを取得して同期します。

クロスフェードの注意

  • 遷移中の新しい切替要求は、現在の遷移が終わるまで受け付けません。
  • Textureは数値のような連続補間ではなく、遷移途中で切り替わります。
  • 「プリセット差分更新の最小値」を上げすぎると段階的に見えます。
  • グローバルではサーバー時刻を基準にするため、参加者間の進行が揃います。
