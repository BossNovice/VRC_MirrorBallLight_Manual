UnityPackageの導入

必要環境とImport手順、導入できたかの確かめ方です。

必要環境

必須 Unity 2022.3.22f1、VRChat Creator Companionで作成したWorldプロジェクト、VRChat Worlds SDK／UdonSharp
任意 AudioLink、LTCGI、VRC Light Volumes。使用する機能だけ導入します。
LTCGI・VRCLightVolumes連携Materialを使う場合は、該当パッケージをMirrorBallLightより先に導入してください。 連携版Shaderはこの2つのPackageのファイルを直接includeするため、後から導入するとImport時にShaderのコンパイルエラーが出ます。通常版のみなら不要です。
Importにかかる時間の大半はShaderのコンパイルです。新規プロジェクトへの初回Importは実測で約128秒でした。2回目以降のUnity起動は10数秒です。時間は環境によって変わります。

Import手順

  1. Unityを閉じる必要はありませんが、Play Modeは終了します。
  2. Unityメニューで Assets > Import Package > Custom Package... を選び、ダウンロードした MirrorBallLightController_*.unitypackage を指定します。
  3. Import一覧は原則として全項目を選択し、Importを押します。
  4. C#とUdonSharpのコンパイルが終わるまで待ちます。Consoleに赤いエラーが残っている間はPrefabを編集しません。
  5. 設定済みサンプルを配置して動作を確認します。
Assets/MirrorBallLight/Samples/にはShape Atlas、2D Cookie、Cubemap Cross、調整用マスクが含まれます。Cubemap／2D TextureのImport設定は適用済みです。

Import後の主なフォルダ

フォルダ 内容
Scripts Controller、Preset、対応UdonSharp Program Asset
Editor 日本語Custom Inspector、Material自動検出、診断ツール
Shaders 通常面、透過面、本体ファセット、連携版Shader
Materials Standard／LTCGI・VRCLightVolumes用の設定済みMaterial 6種
Prefabs 通常版と連携版を内包する統合Prefab
Examples 設定済みサンプルと4×2形状アトラス

既存プロジェクトへ導入する場合

同じパスの旧ファイルは上書き対象です。独自に変更したScript／Shader／付属Materialがある場合はImport前に複製またはGitで退避してください。シーン専用に複製したMaterialは通常そのまま残ります。

重複クラスを作らない： MirrorBallLightController.csを別フォルダへコピーすると同名クラスのコンパイルエラーになります。バックアップはUnityプロジェクト外へ置いてください。

導入成功の判定

  • ConsoleにC#／UdonSharp／Shaderの赤いエラーがない
  • MirrorBallLight_ConfiguredSample.prefabを選択できる
  • Controller Inspectorが日本語の10セクションで表示される
  • Play Modeで壁の光点とミラーボール回転が表示される
