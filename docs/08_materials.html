Material項目 効果
壁・床の基本テクスチャ 元のAlbedo／Base Mapです。
ノーマルマップ 凹凸情報。Texture Import TypeをNormal mapにします。
ノーマルマップの強さ 0で無効、1で標準、2で強調します。
壁・床の基本色 Textureへ乗算される色です。
反射光の基本色 光点Emissionの基準HDR色です。Controllerへ登録している場合は「基本色」から更新されます。
金属感 0は非金属、1は金属寄りです。
滑らかさ 高いほど環境反射が鋭くなります。

反射光以下の演出項目はControllerと同名です。Controllerへ登録している場合はController側を正として設定します。

ガラス・透明／半透明オブジェクト

Material項目 効果
透明度 素材全体のAlpha。Controllerの「透過面の本体透明度」で更新されます。
反射光部分の不透明度 光点部分の見え方。Controllerの「透過面の光点不透明度」で更新されます。
透過マスクの回転追従 透明マスクを投影回転へ追従させます。
深度書き込み 通常OFF。重なり順問題を改善する場合だけONを試しますが、他の透明物を隠す場合があります。
面の描画 Backは表面、Frontは裏面、Offは両面を描画します。ガラス板を両側から見る場合はOffを検討します。
透過描画方式プリマルチプライ、加算、ソフト加算、ディザ透過を切り替えます。
深度フェードCamera Depth Textureを使って交差境界のAlphaとEmissionを弱めます。
透明Shaderは描画順の制約があります。Particle、別のガラス、鏡などと重なる場合はRender QueueとZWriteをシーンごとに確認してください。

Material個別AudioLink・発光パターン

4種類のSurface Shader（通常／透明／LTCGI・VRCLightVolumes通常／同透明）で使用できます。これらはMaterial固有値であり、Controllerの「Shader Global共有を使用」がONでも上書きされません。

項目初期値効果
個別AudioLinkマスクを使用OFFMaterial固有の音声反応領域を有効化します。
AudioLink反応マスク白白＝反応、黒＝音による変化なし。TextureのTiling／Offsetも利用できます。
AudioLinkマスクの強さ10で無効、1で完全適用します。
AudioLinkマスクを反転OFF白黒を反転します。
個別発光パターンを使用OFF反射光へMaterial固有の模様・色を適用します。
発光パターンテクスチャ白RGBを発光色、AlphaまたはRGB輝度を発光マスクとして使用します。
発光パターンの色白Texture色へ乗算するHDR色です。
発光パターンの適用量10で元の反射、1でパターンを完全適用します。
発光パターンを反転OFF発光する場所と消える場所を反転します。
発光パターンのスクロール速度0, 0X／Y方向へUVを毎秒スクロールします。
発光パターンの音連動量0このMaterialだけAudioLink明滅を追加します。

透明Shaderでは個別発光パターンがEmissionだけでなく反射光部分のAlphaにも反映されるため、消灯箇所だけが透明になります。ガラス本体の基礎透明度には影響しません。

個別マスクと発光パターンはミラーボール反射部分だけへ適用されます。LTCGIやVRCLightVolumesから受ける環境照明そのものはマスクしません。

壁・ガラス表面Emission／AudioLink／Mask

4種類のSurface Shaderすべてで、回転する反射光とは独立した表面発光をMaterialごとに設定できます。Controllerやライブプリセットからは上書きされません。

Material項目効果
表面Emissionを使用追加の表面発光をONにします。OFF時は追加Textureを読みません。
表面Emissionテクスチャ壁紙、看板、ガラス模様などの発光RGBを指定します。
表面Emissionカラー／強さHDR色と0～20の倍率を乗算します。
表面Emissionマスクを使用白＝発光、黒＝非発光の専用Maskを有効化します。
Maskの強さ／反転Mask適用量と白黒反転を調整します。

廃止したShader Keyword

Importにかかる時間を短縮するため、Shader Keywordの本数がImport時間を大きく左右するため、軽い機能のKeywordを実行時の切り替えへ移しています。

Materialの設定と描画結果は変わりません。 Inspectorの操作方法も同じです。移行が必要なのは、下表のKeywordをアニメーションクリップやスクリプトから直接操作していた場合だけです。
廃止したKeyword移行先のプロパティInspectorでの項目
_MB_DEPTH_FADE_UseDepthFade深度フェードを使用
_MB_MATERIAL_AUDIO_MASK_UseMaterialAudioMask個別AudioLinkマスクを使用
_MB_SURFACE_EMISSION_AUDIOLINK_UseSurfaceEmissionAudioLink表面EmissionをAudioLink連動
_MB_ATLAS_SEED_FADEなし（Controllerの設定が決めます）—
_MB_FACET_SEED_FADEなし（同上）—

アニメーションからの移行手順

  1. 該当のアニメーションクリップを開き、Materialの Keyword を切り替えているカーブを探します。
  2. そのカーブを削除し、代わりに上表の移行先プロパティを 0（OFF）または 1（ON）で操作するカーブへ置き換えます。
  3. シードの自動フェード2種はControllerの設定が決めるため、Material側での切り替え対象ではありません。Controllerの項目を操作してください。
Materialに残っている廃止Keywordは、Tools > MirrorBall Light > 診断・最適化 の「安全に自動修正」で削除できます。Keywordと設定値が食い違っている場合は、どちらの状態で動作するかも表示します。自動修正が演出設定そのものを書き換えることはありません。

Controller連動とMaterial直編集

  • Controllerの対象Materialへ登録したSurfaceは、色・明るさ・共通AudioLink・光点・Cookie・距離・Texture参照・共通Keywordを更新されます。
  • Base Texture、Normal Map、基本色、金属感、滑らかさ、Material個別AudioLinkマスクと個別発光パターンはMaterial側で設定します。
  • 本体は「Controllerの色・電源・AudioLink設定と連動」がONの時だけ演出値が同期します。
  • Edit Mode変更をAssetへ残すには「現在の設定をマテリアルへ反映・保存」を押します。
