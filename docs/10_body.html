ミラーボール本体のファセット

本体球の鏡片の見え方と、暗い場所での表示の担保です。

4. ミラーボール本体ファセット

表示名 初期値 効果
本体ファセット用マテリアル（任意） 任意 通常版本体Material。Controller連動対象です。
連携版本体ファセット用マテリアル（任意） 任意 LTCGI・VRCLightVolumes版本体Material。
Controllerの色・電源・AudioLink設定と連動 ON 本体の色・発光・AudioLink状態をControllerへ合わせます。
本体ファセットの明るさ倍率 1 / 0–4 本体発光だけを倍率調整します。
本体ファセットのパターンシード 0 鏡片の傾き・色むら・明滅パターンを変更します。
本体シードを自動フェード OFF ONにすると下の周期ごとに新しいシードへ滑らかにクロスフェードします。光点Atlas側のシードフェードとは独立した周期で動作します。
本体シード変化の周期（秒） 20 / 1–300 次のシードへ完全に切り替わるまでの秒数です。サーバー時刻基準のため全員が同じタイミングで切り替わります。
本体表示モード 通常版 通常版本体と連携版本体のActiveを排他的に切り替えます。
通常版本体オブジェクト Prefab設定済み 通常版選択時だけActiveになります。
LTCGI・VRCLightVolumes版本体 Prefab設定済み 連携版選択時だけActiveになります。

「ミラーボールRendererから本体Materialを取得」はRendererから対応Material参照を補完します。

MirrorBallFacetBody

分類 項目 効果
基本 鏡片の基本色／金属感／滑らかさ 本体の基礎PBR表現です。暗所では基本色を完全な黒にしないでください。
Facet Layout 横方向の鏡片数／縦方向の鏡片数 鏡片の密度です。初期値48×24。
Facet Layout 鏡片の形状 Square等の鏡片輪郭を選びます。
Facet Layout 目地の太さ／目地境界のぼかし／目地の色 鏡片の境界を作ります。太すぎると球全体が暗くなります。
Facet Normal 鏡片面の平面化 球の連続法線を鏡片ごとの平面へ近づけます。初期0.88。
Facet Normal 鏡片ごとの傾き 法線をランダムにずらし反射方向を散らします。
Facet Normal 鏡片ごとの色むら 均一さを崩します。
暗所対策 暗所での最低表示明るさ 環境光が弱い場所でも真っ黒になるのを防ぎます。初期0.08。
反射 反射Cubemap（任意）／反射・スパークル色／Cubemap反射の強さ 任意Cubemapの反射と、反射・きらめきのHDR色を調整します。
反射Reflection Probeをフォールバックに使用指定Cubemapが未設定または黒い場合にワールドのReflection Probeへ切り替えます。
反射反射がない場合の色／明るさReflection Probeも利用できない場合の最低表示を指定します。
スパークル スパークルの強さ／スパークルの鋭さ／スパークルの明滅量／スパークルの明滅速度 視線と鏡片法線が合う箇所のきらめきの強度、範囲、時間変化を調整します。
安全 発光の上限 本体Emissionの最大値です。初期8。
AudioLink AudioLinkを使用／反応する帯域（0低音～3高音）／音によるスパークル増加／音声反応のしきい値／AudioLinkテストモード／テスト音量 本体スパークルを指定帯域へ反応させます。テストモードは公開前にOFFにします。
本体が黒い場合は、基本色、暗所での最低表示明るさ、目地の太さ、Cubemap、Controllerの電源・本体明るさ倍率の順で確認します。

フォールバック表示

  • 受光面：フォールバック発光色と発光量で、主反射が弱い場合の最低表示を指定します。
  • 本体：指定Cubemapが未設定または黒い場合、Reflection Probeを参照します。
  • Reflection Probeもない場合：本体Materialの「反射がない場合の色／明るさ」を使います。
  • AudioLinkがない場合：従来どおり音声値0として通常演出を継続します。
  • 形状TextureやCookieが未設定の場合：Shader既定の白Textureから基本形状を表示します。
通常運用では受光面のフォールバック発光量を0のままにし、設定切り分け時だけ0.1～0.3へ上げる方法を推奨します。
