# 光点形状アトラス サンプル

`SampleShapeAtlas_4x2.png` は、横4・縦2に8種類の白い形状マスクを並べた透明PNGです。

| 番号 | 上からの位置 | 形状 |
|---:|---|---|
| 0 | 1行1列 | 四角 |
| 1 | 1行2列 | 丸 |
| 2 | 1行3列 | ひし形 |
| 3 | 1行4列 | 十字 |
| 4 | 2行1列 | 星 |
| 5 | 2行2列 | ハート |
| 6 | 2行3列 | 六角形 |
| 7 | 2行4列 | リング |

## Controller設定

1. `複数形状アトラスを使用` をONにします。
2. `光点形状アトラス` に `SampleShapeAtlas_4x2.png` を設定します。
3. `アトラス横分割数` を4、`アトラス縦分割数` を2にします。
4. `使用する形状数` を8にします。
5. `形状配置シード` を変更すると、形状の種類は同じまま配置だけを変更できます。
6. `現在の設定をマテリアルへ反映・保存` を押します。

## 独自アトラスの作成規則

- 各セルは同じ大きさにしてください。
- 左上から右へ、次に下の行へ並べます。
- 形状部分は白、不使用部分は透明または黒にします。
- セル端から十分な余白を取り、隣の形状がフィルタリングで混ざらないようにします。
- PNGを推奨します。UnityのImport設定は `Wrap Mode: Clamp`、`Mip Maps: OFF`、`Alpha Is Transparency: ON` にしてください。
- `Tools > MirrorBall Light > 診断・最適化` は、**形状アトラスに指定したTextureのこの3つ**を見ています。違っていれば警告し、`安全に自動修正` を押すとこの値へ変更します。
- 同梱サンプルを指定した直後に、診断がWrap Modeを警告することがあります。`安全に自動修正` を押すか、手でClampへ変えてください。
- **Wrap Modeの違いで見た目は変わりません。** Shader側でUVを0〜1へ丸め、範囲外を捨ててから引いているためです。Clampに揃えるのは、診断が出す警告をなくし、設定を1つに統一するためです。
- `使用する形状数` は `横分割数 × 縦分割数` 以下にしてください。

アトラスはセルごとに1回だけサンプリングされます。個別Textureを複数サンプリングする方式より、VRChat向けの負荷とサンプラー使用数を抑えられます。
