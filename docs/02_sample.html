設定済みサンプルで最短確認

壁・ミラーボール・Spot Light・Controllerを関連付け済みのPrefabで、動くところまでを確かめます。

配置する

  1. Projectで Assets/MirrorBallLight/Examples/ConfiguredSample を開きます。
  2. MirrorBallLight_ConfiguredSample.prefabをHierarchyへドラッグします。
  3. Scene内で壁が他のオブジェクトに隠れない位置へ移動します。
  4. Play Modeへ入り、壁の光点、ミラーボール回転、Spot Lightを確認します。
初期状態は通常版です。LTCGI・VRCLightVolumesを導入していなくても確認できます。

Prefab内の設定

オブジェクト 役割 設定済み内容
MirrorBallLight_ConfiguredSample ルート／Controller UdonSharp Program Asset、対象Material 6種、電源、各参照
mirrorball 回転Root 通常版本体と連携版本体を子に保持
mirrorball_light_wall 反射確認用の壁 Standard通常面Materialを割り当て
mirrorball_spotlight ミラーボールへの照射 Spot 45°、Range 12、Intensity 2、影なし、ボール方向へ設定

Prefabのまま使うときの注意

Hierarchyへ置いたサンプルはPrefabのインスタンスです。Inspectorで値を変えると、その項目名が太字になり、左に青い線が付きます。これは「元のPrefabとは違う値になっています」という印です。

やりたいこと操作効き方
このシーンのこの1台だけ変えたいそのまま値を変える置いたインスタンスだけが変わります。ふだんはこれで十分です
変更を元のPrefabへ戻したい項目を右クリック → Revert元のPrefabの値へ戻ります
同じPrefabを置いた全部へ広げたい項目を右クリック → Apply付属のPrefabそのものが書き換わります

右クリックのほかに、Inspector上部の Overrides から、変更点をまとめて確認して適用・取り消しすることもできます。表示や項目名はUnityの版によって変わります。 どちらから操作しても、下の注意は同じです。

Apply は付属のPrefabを書き換えます。 ワールド固有の調整を Apply すると、他のシーンで置いたものや、次に置くものにも付いて回ります。迷ったら Apply は押さないでください。 インスタンス側の変更だけで足ります。
自分のワールド用に作り込むなら、Hierarchyのインスタンスを右クリックして Prefab > Unpack するか、別名のPrefabとして保存してください。付属のPrefabを直接育てると、次の版を入れたときに手作業が要ります。

正しく動かない場合の確認順

  1. Consoleの赤いエラーをすべて解消する
  2. Controllerの「ミラーボール本体」がmirrorballを参照しているか
  3. 「反射を表示するマテリアル」に壁のMaterialが含まれるか
  4. MaterialのShaderがMirrorBallLight/MirrorBallSurfaceAutoか
  5. 「電源状態」がON、「反射光の明るさ」が0より大きいか
