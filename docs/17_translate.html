既存の壁・ガラスMaterialを変換

PoiyomiのTranslate／Translate Copyに近い操作で、既存設定を移します。

このページでできること

既存の壁・ガラスは、HierarchyまたはProjectの右クリックメニューから設定を可能な範囲で引き継いで変換できます。元Materialを保持する場合はTranslate Copyを使用してください。

Material Translate／Translate Copyの詳細

推奨手順：Translate Copy

  1. Hierarchyで壁、床、天井、ガラスのGameObjectを選択します。
  2. 右クリックして MirrorBall Light > マテリアル > Translate Copy（複製して変換・推奨） を選びます。
  3. 選択Objectと子ObjectのRendererに使われているMaterialが重複なしで処理されます。
  4. 変換コピーが Assets/MirrorBallLight/Generated/ConvertedMaterials/ に作られ、Rendererへ再割り当てされます。
  5. 同じSceneにMirrorBallLightControllerがある場合は、変換Materialが対象一覧へ追加されます。
初回は必ずTranslate Copyを推奨します。見た目を確認した後、不要になった元Materialを手動で整理してください。

右クリックメニュー

メニュー動作
Translate（直接変換）元Material自体のShaderを変更します。Undo対応ですが、同じMaterialを共有する全Objectへ影響します。
Translate Copy（複製して変換・推奨）元Materialを保持し、変換コピーを作成して選択Rendererへ割り当てます。
Translate to LTCGI・LightVolumes通常面／透明面を自動判定し、照明連携版Shaderへ直接変換します。
Translate Copy to LTCGI・LightVolumes照明連携版Materialのコピーを作成します。LTCGIとVRC Light Volumesを先に導入してください。
変換内容を確認Materialを変更せず、元Shader名と自動判定された変換先を最大20件表示します。

同じメニューはProjectウィンドウでMaterial Assetを右クリックした場合にも表示されます。Project側のTranslate CopyはコピーAssetを作成し、作成物を選択状態にします。

通常面／透明面の自動判定

次の情報を順に確認し、ひとつでも透明条件に該当すればTransparent版へ変換します。

  • Shader名にTransparent、Glass、Fadeが含まれる
  • RenderType TagがTransparent
  • Render Queueが3000以上
  • _Surface、_Modeなど一般的な透明設定
  • Base Color／ColorのAlphaが1未満
Cutoutだけを使うMaterialや独自Shaderでは判定が異なる可能性があります。実行前に「変換内容を確認」を使用してください。

引き継ぐ設定

元Materialの候補MirrorBallLight側

Bump Map／Normal Map、Normal強度ノーマルマップと強さ
Emission Map／Color／強度表面Emission Texture／HDR色／強さ

Smoothness／Glossiness／Roughness滑らかさ。Roughnessは反転して変換

完全変換できない設定

Poiyomi、lilToon、独自Shaderの次の機能はMirrorBallLight側に同じ機能がないため、完全には再現できない可能性があります。

  • 複数レイヤーTextureと独自ブレンド
  • MatCap、Rim Light、Outline、Glitter、Decal
  • 複数Emissionレイヤー、独自Emissionアニメーション、特殊Blend
  • Stencil、特殊Depth、GrabPass、独自Render State
  • Shader固有のマスクPackingやUVアニメーション

変換後はSceneビューでBase Texture、Normal、透明度、表面Emission／Maskを確認し、Controllerの設定をMaterialへ反映してからVRChatへアップロードしてください。

元へ戻す方法

  • Translate直後ならUnityのUndoを使用します。
  • Translate CopyではRendererへ元Materialを再割り当てします。
  • 生成Materialが不要なら、参照されていないことを確認してからGenerated/ConvertedMaterials内を手動で整理します。
