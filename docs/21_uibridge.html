UIボタンから操作する

ControllerのInspectorからUIボタンを自動作成し、電源とプリセットを切り替えます。

Button・UI Bridge・Controller参照・On Click配線は、まとめて自動設定できます。既存Buttonへ追加する方法と、新しいButtonを作る方法の両方があります。

やりたいこと

ワールドに置いたUIボタンを押して、ミラーボールの電源とプリセットを切り替えます。スクリプトは書きません。

ボタン側の設定に MirrorBallLightUIBridge という部品を1つ挟みます。ControllerのInspectorから作成画面を開き、「どの操作をするか」を選ぶだけで、必要な部品と配線が揃います。

この部品が無くても、実は動きます。 Controllerには TogglePower や NextPreset といった入口があり、ボタンの On Click から名前を打てば呼べます。

ただし2つ困ることがあります。名前を打ち間違えても、押すまで分かりません。 それと、番号を指定してプリセットを切り替える操作は、ボタン1つでは順番を守れません。 先に番号を渡してから呼ぶ必要があり、これまでは補助スクリプトを書くしかありませんでした。

この部品は、その2つを引き受けます。

自動作成する（推奨）

  1. Hierarchyで MirrorBallLightController の付いたGameObjectを選びます。
  2. Inspectorの「2. ライブプリセット」を開き、「UI Bridge付きButtonを自動作成…」を押します。
  3. 作成方法を選びます。
    • 新しいButtonを作成：CanvasまたはPanelなどのRectTransformを「配置先UI」へ指定します。
    • 既存Buttonへ追加・更新：すでに見た目を作ってあるButtonを「対象Button」へ指定します。
  4. 操作を選びます。番号指定の操作では、先頭を0としたプリセット番号も指定します。
  5. 新規作成ではGameObject名と表示文字を確認します。日本語が出ないフォントの場合は、日本語対応Fontを「表示フォント」へ指定します。
  6. 「Buttonを作成して配線」または「既存Buttonへ追加・配線」を押します。
  7. 作成されたButtonの On Click () に、同じGameObjectのUdonBehaviourと SendCustomEvent (string) / Execute が1件入っていることを確認します。
既存Buttonへ追加しても、画像・色・RectTransformは変えません。「表示文字も変更」をONにした場合だけ、子にあるUnity UI Textの文字と任意のFontを変更します。TextMeshProの文字は変更しません。
同じButtonへ自動設定をやり直してもOn Clickは重複しません。Controller・操作・プリセット番号だけを更新します。作成直後ならUnityのUndoでも戻せます。

手動で設定する場合

  1. Buttonと同じGameObjectへ MirrorBall Light UI Bridge を追加し、Controller・操作・必要ならプリセット番号を設定します。
  2. Buttonの On Click () で + を押し、同じGameObjectを指定します。
  3. UdonBehaviour → SendCustomEvent (string) を選び、文字入力欄へ Execute と入れます。大文字小文字まで一致させます。
ボタン1つにつき、この部品を1つ置きます。「電源」「次」「前」の3つを作るなら、それぞれのButtonへ1つずつ設定します。

選べる操作

操作すること番号を使うか
電源を切り替えるONなら消し、OFFなら点けます使いません
電源をONにするすでにONなら何も変わりません使いません
電源をOFFにするすでにOFFなら何も変わりません使いません
次のプリセット一覧の次へ。末尾なら先頭へ戻ります使いません
前のプリセット一覧の前へ。先頭なら末尾へ回ります使いません
番号を指定して適用指定した番号へ切り替えます。クロスフェードします使います
番号を指定して即時適用指定した番号へすぐ切り替えます。クロスフェードしません使います

プリセット番号は、Controllerの「プリセット一覧」の並び順です。先頭が0です。

誰に見えるか

この部品は、見える範囲を決めません。 決めているのはController側の「動作範囲」と「プリセットの動作範囲」です。

ボタンから操作しても、Interactで触ったときや他のUdonから呼んだときと同じ扱いになります。所有権の取得もController側で行われます。この部品が同期変数へ直接書くことはありません。

範囲と所有権の考え方は他のUdonから操作するにあります。

効いたかどうかを見る

押した結果は、この部品の lastResultCode に入ります。0が成功です。

番号意味見るところ
0成功しました―
1プリセットが使えませんControllerの「ライブプリセットを使用」がOFF、または一覧が空です
2その番号のプリセットが未設定です一覧のその行が空欄です
3切替中だったので予約しました後で適用されます
4切替中だったので無視しましたControllerの「切替中の要求を1件だけ予約」がOFFのときの既定です
5Controllerが未設定ですこの部品のInspectorに赤い警告が出ています
6操作の番号が範囲外です通常は起きません。手で値を書き換えた場合です

5と6はこの部品が出す番号で、Controller側にはありません。設定のミスと、Controllerが返した結果を混ぜないためです。

気をつけること

番号は範囲を超えてもエラーになりません

一覧が3件のときに10番を指定すると、エラーにならず、末尾の3番目が適用されて「成功」が返ります。 Controller側が番号を丸めるためで、他のUdonから呼んだときも同じです。番号を変えたのに同じプリセットが出るときは、一覧の件数を確かめてください。

押しても何も起きないとき

  1. 自動作成をもう一度実行します。同じButtonならOn Clickを重複させず、Controller・操作・配線を更新します。
  2. 手動設定の場合は、イベント名が Execute になっているかを確認します。前後の空白や大文字小文字も一致させてください。
  3. Controllerの欄が空でないか。 空のときはInspectorに赤い警告が出て、押すとConsoleにも警告が出ます。
  4. On Click の左下がボタン自身のGameObjectになっているか。別のオブジェクトを入れていると、そちらのUdonBehaviourを探しに行きます。
  5. プリセットの操作なら、Controllerの「ライブプリセットを使用」がONか。
  6. ここまでで直らないときは、Canvas側が押せない設定です。Tools > MirrorBall Light > 診断・最適化 を実行してください。R30.5から、World Spaceでない・コライダーが無い・Graphic Raycasterが無いなどを名指しで表示します。詳しくは ボタンを押しても何も起きない を参照してください。
World Spaceでないボタンと、コライダーの無いCanvasは、Unity Editorの再生では押せてしまいます。 VRChatでだけ効きません。

この部品は同期しません

部品自体はネットワーク同期を持ちません。押した結果が全員に届くかどうかは、Controller側の動作範囲だけで決まります。
