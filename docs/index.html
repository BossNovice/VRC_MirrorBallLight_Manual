使えない環境と注意事項

項目内容
必須環境VRChat Creator Companionで作成したWorldプロジェクト、VRCSDK Worlds、UdonSharp、Unity 2022.3系のVRChat指定バージョン、Built-in Render Pipeline
Avatar対応していません。 ワールド専用です
Quest／Android対応していません。 Surface Shaderを使えないため、PC向けです
連携版Shader対応する外部パッケージが無い状態ではコンパイルできません。 ガードは入れていません。MirrorBallLightより先に導入してください
ライセンス現時点で明示していません。 第三者への再配布や改変版の公開の条件は、リポジトリ所有者へ確認してください
光点は実際の反射光ではありません。壁MaterialのEmissionとして描いています。 また、対象Materialの値を書き換える方式なので、同じMaterialを別の部屋でも使う場合は複製してください。
