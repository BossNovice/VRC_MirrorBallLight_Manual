更新される方へ

R27.1／R27.2／R27.3 をお使いの場合は必ず更新してください。 これらの版はImport時にUdonSharpのコンパイルが失敗し、プロジェクト内のU#スクリプト全体が壊れます（R27.4で修正）。
R26／R26.1／R27 をお使いの場合は更新を推奨します。 シードの自動フェードで、パターンが途中からまったく変化しなくなる不具合がありました（R27.6.3で修正）。

R27.4以降の主な変更

版内容利用者への影響
R28Shader Global共有の書き込みを、値が変わったときだけ行うよう変更設定と描画結果は変わりません。Global共有は1つのControllerだけで使用してください（複数ある場合は診断ウィンドウが警告します）
R27.6.3シード自動フェードでパターンが途中から変化しなくなる不具合を修正同じ設定でもパターンの出現順序が従来と変わります。形状の種類・パラメーターの意味・操作方法・Materialの設定は変わりません
R27.6.1／R27.6.2シード自動フェードを停止したときにパターンが固まる／前のシードが残る不具合を修正設定変更は不要です
R27.6.2Editorのドメインリロードのたびに走っていた余分なUdonSharpコンパイルを停止。診断ウィンドウへ依存Package確認とKeyword移行診断を追加Editorの待ち時間が減ります
R27.6Importにかかる時間を約12分から約1.5分へ短縮Materialの設定と描画結果は変わりません。廃止したShader Keywordをアニメーションで操作していた場合は移行が必要です（Materialを参照）
R27.4Import時のUdonSharpコンパイルエラーと、光点形状9種のMaterial Inspector表示エラーを修正形状の選択が日本語のポップアップになります

版ごとの詳しい移行手順は GitHub版マニュアル の「出発バージョン別の移行ガイド」を参照してください。
