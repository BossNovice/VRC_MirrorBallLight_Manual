ライブプリセットとクロスフェード

演出をまとめて切り替えます。作り方と、実行中に切り替えるイベントです。

2. ライブプリセット

表示名 初期値 効果
ライブプリセットを使用 OFF Preset配列と切替処理を有効にします。
開始時に選択中プリセットを適用 ON Start時に現在の同期番号を適用します。
プリセットの動作範囲 グローバル ローカルは自分だけ、グローバルは選択番号と開始時刻を同期します。
プリセット一覧 配列 適用順。番号は0から始まります。
選択プリセット番号（0から） 0 ApplySelectedPresetで適用する番号です。
クロスフェード時間（秒） 0.8 0で即時、値を増やすと演出設定を補間します。
クロスフェード曲線 滑らか 線形／滑らか／ゆっくり開始／ゆっくり終了です。

プリセットを作る

  1. Controllerで「新しいプリセットを追加」を押します。子GameObjectとPresetコンポーネントが追加されます。
  2. Controller側で基準となる見た目を作ります。
  3. 「選択プリセット番号」を保存先番号へ合わせます。
  4. 「現在値を選択プリセットへ保存」を押します。
  5. 必要数だけ繰り返し、「一覧を子から自動検出」で配列を整理します。
  6. 「選択番号をプレビュー適用」でEdit Modeの見た目を確認します。

演出プリセット

「演出プリセットを追加（Slow Drift／Club Pulse／Jump A〜C）」を押すと、シードフェードを使った既製の演出セットが子GameObjectとして5つ作成されます。現在のController設定を土台に、演出ごとに異なる値だけを差し替えるため、色や明るさなど作り込んだ設定はそのまま引き継がれます。追加Assetは同梱されません。

プリセット 動作 Atlasシード周期 本体シード周期
Slow Drift 穏やかに変化し続ける 67秒 19秒
Club Pulse 短周期で派手に切り替わる 8秒 3秒
Jump A／B／C 自動フェードなし。プリセット切替で絵柄が変わる ― ―
Slow DriftとClub Pulseは周期を整数比にしていません。67秒と19秒のように揃わない値にすることで、壁の光点と本体の鏡片が同時に模様替えして見える反復感を避けています。

Jump A〜Cは自動フェードを使わず、固定シードの値だけが異なるプリセットです。NextPresetなどで切り替えると絵柄が変わり、遷移自体はプリセットのクロスフェードが滑らかにします。追加時にクロスフェード時間を1.5秒以上、曲線を「滑らか」へ寄せるのはこのためです。

Presetに保存される項目

Presetは次の演出値を保持します。Controllerの必須参照、電源範囲、最適化設定などは切り替えません。

分類 保存される項目
回転・反射 回転速度、基本色、反射光明るさ、通常面／透過面明るさ、透過Alpha
カラー ランダム色、彩度、色相速度、色明滅
AudioLink 用途別帯域、明るさ／サイズ／色の増加、履歴モード／遅延
投影Cookie 使用状態、方式、2D／Cube Texture、強さ、色、Tiling、Offset、回転
光点 タイル数、サイズ、ぼかし、比率、形状、単一Texture、アトラス設定、点灯割合、切替、明滅
シード 光点形状Atlasのシード・自動フェード・周期。本体ファセットのシード設定は「本体シード設定をこのプリセットで指定」がONのPresetのみ
距離 フェード開始／終了、減衰曲線
古い版で作成したPresetには本体ファセットのシード設定を保存する項目がありません。そのPresetへ切り替えても本体シード設定はControllerの現在値が維持されます（意図しない上書きを避けるための仕様）。持たせたい場合は対象番号を選び「現在値を選択プリセットへ保存」を押してください。保存時に自動でONになります。

Custom Event名 動作
NextPreset 次のPresetへ移動し、末尾から先頭へ循環します。
PreviousPreset 前のPresetへ移動し、先頭から末尾へ循環します。
ApplySelectedPreset 「選択プリセット番号」をクロスフェード適用します。
ApplySelectedPresetImmediately 同番号を補間なしで即時適用します。

TogglePower／TurnOn／TurnOff 電源UI用イベントです。

Unity UI Buttonへ接続

  1. ButtonのOn ClickへController GameObjectを登録します。
  2. UdonBehaviour.SendCustomEvent(string)を選びます。
  3. 文字列へ上表のEvent名を正確に入力します。
大文字・小文字を含め完全一致が必要です。グローバル切替では操作したPlayerがOwnershipを取得して同期します。

クロスフェードの注意

  • 遷移中の新しい切替要求は、現在の遷移が終わるまで受け付けません。
  • Textureは数値のような連続補間ではなく、遷移途中で切り替わります。
  • 「プリセット差分更新の最小値」を上げすぎると段階的に見えます。
  • グローバルではサーバー時刻を基準にするため、参加者間の進行が揃います。

演出を選ぶ・比較する

Controller Inspector上部の「演出プリセットを選ぶ・比較する…」から、演出ライブラリ8種類または登録済みプリセットを選びます。差分は回転・色・光点・形状／シード・AudioLink・投影・距離ごとに表示し、色は変更前後のスウォッチで確認できます。

  1. 変更項目を確認します。
  2. 「試す」で一時反映、「元に戻す」で復元します。
  3. 残す場合は「この演出を適用」を押します。Undo／Redoで戻せます。
  4. 「この演出だけプリセット一覧へ追加」は既存一覧の末尾に1件だけ追加します。

追加はライブプリセット・AudioLink・ランダム点灯を自動で有効にしません。Calm Rotationはゆっくりした回転、Sparse Glintsは小さく疎な光点、Music Responseは音への反応値を用意します。必要条件を確認してください。

プレビューは閉じる・保存・Play Mode移行・スクリプト再読込で復元されます。別のInspectorで変更された値を保持して競合を警告します。Editorの比較と実音楽・VRChat実機の確認は別です。

時間指定の演出シーケンス

Proの「2. ライブプリセット」で「時間指定の演出シーケンスを追加・選択…」を押します。使用OFF・自動再生OFF・ステップ0件で作られます。既存Prefabへ自動では追加しません。

  1. Controllerのライブプリセットを用意し、使用を有効にします。
  2. Sequenceへステップを追加して「番号: 名前」の一覧と継続時間を設定します。番号の直接入力、上下移動・複製・削除ができます。
  3. 合計継続時間と入力診断を確認します。不正な番号・未設定プリセット・件数不一致・無効な時間は該当ステップを示します。
  4. シーケンスの使用を有効にして、開始または自動再生を選びます。設定編集はEdit Modeで行います。

1〜256ステップ、継続時間0.05秒〜24時間。合計は設定値の和で、クロスフェード完了待ちを含む実測再生時間ではありません。継続時間は選択開始から数えます。遷移の完了を待つため、実際の次ステップ開始が遅れる場合があります。ループOFFでは最後の演出を保持して停止します。

イベント動作
StartSequence停止中から先頭で開始
StopSequence現在の演出を保持して停止
RestartSequence先頭から再生し直す
PauseSequence継続時間の残りを保持。回転・音楽反応・進行中のクロスフェードは継続
ResumeSequence保持した残り時間で同じステップから再開
NextStep次へ進む。一時停止中は一時停止を保持し、次の全継続時間を用意。クロスフェード中は拒否

SequenceのUdonBehaviourへ上表の名前をSendCustomEventで送ります。Play ModeのInspectorと設置型パネルでも操作できます。UI Bridgeの既存操作番号は変更しません。

ローカル範囲は手元で再生し、共有範囲はController所有者だけが再生します。「再生状況を共有パネルへ配信」とControllerの配信元を設定すると、状態・カーソル・残り時間をControllerへ配信します。既存Sequenceの共有表示は既定OFF、パネル配線時に有効にします。1つのControllerを別のSequenceが同時に駆動することはできません。

所有権・範囲・Controller参照が変わると停止します。所有権の自動取得と所有者変更後の自動再開はありません。新しい所有者が明示的に開始します。途中参加の表示は最新の共有スナップショットを使う設計ですが、VRChat実ネットワークの確認は未実施です。

空配列・範囲外／未設定のプリセット・不正な時間（NaN・Infを含む）は開始を拒否し、一時停止中も入力を検査します。lastResultCodeは0=成功、1=無効、2=Controller／プリセット無効、3=ステップ不正、4=所有権・範囲・参照変更、5=切替拒否、6=クロスフェード中、7=配信元／再生ドライバー競合です。
