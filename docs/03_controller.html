03 / CONTROLLER

Controllerの基本・本体・実光・最適化

Inspectorの1・3・4・9・10番と、最下部の保存ボタンを説明します。

ControllerのInspectorの使い方

設定項目は10個の折りたたみに分かれています。最初は「1. 基本設定・電源・対象Material」だけが開いています。 導入だけならここしか触りません。

  1. HierarchyでControllerが付いたGameObjectを選びます。設定済みサンプルなら MirrorBallLight_ConfiguredSample です。
  2. Inspectorの上にある「すべて開く」「すべて閉じる」で、10個の折りたたみをまとめて操作できます。必要な番号だけ開くほうが探しやすくなります。
  3. 設定を変えます。
  4. Inspectorの一番下にある「現在の設定をマテリアルへ反映・保存」を押します。これを押すまでMaterialへは書かれません。
折りたたみの開閉は、Unityを開いている間だけ覚えています。 Unityを起動し直すと、また「1. 基本設定」だけが開いた状態に戻ります。設定が消えたわけではありません。

Inspectorの下に出る警告

必須の設定が空のとき、保存ボタンの下に出ます。赤はこのままでは動きません。

表示意味対処
ミラーボール本体が未設定です赤（エラー）1番の「ミラーボール本体」へ回転の基準にするTransformを入れます
反射を表示するマテリアルが未設定です黄（警告）1番の「対象マテリアルをシーンから自動検出」を押します

変えたのに見た目が変わらないとき

  1. 「現在の設定をマテリアルへ反映・保存」を押したかを確かめます。いちばん多い原因です。
  2. 壁を増やした後なら、先に「対象マテリアルをシーンから自動検出」を押します。一覧に無いMaterialへは書かれません。
  3. Play Mode中に変えた値は、Play Modeを抜けると元に戻ります。 ただしMaterialやTexture Import設定のようなアセットそのものへの変更は残ります。 Play中に押した「現在の設定をマテリアルへ反映・保存」の結果は残り、Controllerの設定値だけが戻る、という食い違いが起きます。設定はPlay Modeを抜けてから変えてください。
  4. それでも変わらなければ、10番の「診断・最適化ウィンドウを開く」で原因を探します。

1. 基本設定・電源・対象Material

表示名 初期値／選択 効果
動作範囲 グローバル ローカルは自分だけ、グローバルは電源状態を全員へManual Syncします。
電源状態 ON 反射、本体連動、実光を点灯／消灯します。
このオブジェクトをクリックして切替 ON Controller GameObjectへのInteractで電源を切り替えます。Colliderが必要です。
消灯中は回転を停止 ON OFF中の回転位相進行を停止し、再点灯時に続きから回します。
電源フェード時間（秒） 0.5 / 0–5 点灯と消灯を滑らかに補間します。0は即時です。
ミラーボール本体 必須 位置・回転の基準Transformです。光点投影と表示回転の中心になります。
照射スポットライト（任意） 任意 投影方向と位置の基準です。未指定時はボール位置と下向きを使用します。
反射を表示するマテリアル 配列 Controllerが値を書き込むSurface Material一覧です。

対象マテリアルをシーンから自動検出

シーン内の対応Shaderを使うMaterialを、非アクティブObjectも含めて重複なしで検出し、一覧を置き換えます。新しい壁やガラスを追加した後に実行します。

3. アバターへの実光反映（PC向け）

表示名 初期値 効果
アバター用リアルタイムライト（任意） なし アバターへ当たるPC向けRealtime Light。負荷のため1灯・影なし推奨です。
VRCLightVolumes用オブジェクト（任意） なし 電源と連動してActiveを切り替える別の子GameObjectです。Controller自身は指定不可です。
アバター用ライトの明るさ 1.5 / 0–10 Realtime Lightの基準Intensityです。
アバター用ライトの範囲 8 / 0.1–30 Realtime LightのRangeです。広げすぎると影響範囲と負荷が増えます。
反射光の色を使用 ON ONはControllerの基本色、OFFはLight側の色を維持します。
AudioLink入力AudioSource（任意） なし アバター実光の音量解析元です。壁ShaderのAudioLink入力とは別です。
アバターライトの反応帯域 0 / 0–3 実光の音連動に使う周波数帯を選びます。
アバター用ライトの音連動量 0.5 / 0–2 AudioSource解析結果によるIntensity増加量です。

「アバター用ライトを安全設定」はPoint／Realtime／影なしへ整えます。詳細は連携ページを参照してください。

4. ミラーボール本体ファセット

表示名 初期値 効果
本体ファセット用マテリアル（任意） 任意 通常版本体Material。Controller連動対象です。
連携版本体ファセット用マテリアル（任意） 任意 LTCGI・VRCLightVolumes版本体Material。
Controllerの色・電源・AudioLink設定と連動 ON 本体の色・発光・AudioLink状態をControllerへ合わせます。
本体ファセットの明るさ倍率 1 / 0–4 本体発光だけを倍率調整します。
本体ファセットのパターンシード 0 鏡片の傾き・色むら・明滅パターンを変更します。
本体シードを自動フェード OFF ONにすると下の周期ごとに新しいシードへ滑らかにクロスフェードします。光点Atlas側のシードフェードとは独立した周期で動作します。
本体シード変化の周期（秒） 20 / 1–300 次のシードへ完全に切り替わるまでの秒数です。サーバー時刻基準のため全員が同じタイミングで切り替わります。
本体表示モード 通常版 通常版本体と連携版本体のActiveを排他的に切り替えます。
通常版本体オブジェクト Prefab設定済み 通常版選択時だけActiveになります。
LTCGI・VRCLightVolumes版本体 Prefab設定済み 連携版選択時だけActiveになります。

「ミラーボールRendererから本体Materialを取得」はRendererから対応Material参照を補完します。

9. VRCLightVolumes・LTCGI連携

「すべてON／すべてOFF」は、対象Materialと本体Materialのうち_LightVolumes／_LTCGIを持つものだけを一括変更し、Material Assetへ保存します。通常版Materialには影響しません。

10. 最適化・診断

表示名 初期値 効果
Shader Global共有を使用（推奨） ON 共通パラメーターをMaterialごとではなく一度だけ更新します。同一シーンのGlobal共有Controllerは1個だけにします。
投影回転をGPUで計算（推奨） ON 回転によるMaterial更新をGPUへ移します。Global共有ON時のみ有効です。
表示用ミラーボール本体も回転 ON 投影だけでなく実際のTransformも回転します。
マテリアル更新頻度（回/秒） 30 / 10–90 動的値の更新上限。低いほどCPU負荷が下がり、高いほどフェードが滑らかです。
プリセット差分更新の最小値 0.001 クロスフェード中の微小な更新を省略する閾値。大きいほど軽量ですが段差が出やすくなります。

「診断・最適化ウィンドウを開く」から構成検査と推奨修正を実行できます。

共通ボタン

すべて開く／すべて閉じる 10セクションの折り畳み状態を一括変更します。
現在の設定をマテリアルへ反映・保存 Controllerの現在値、Shader Keyword、Texture参照を対象Materialへ反映し、Assetとして保存します。アップロード前に実行してください。
