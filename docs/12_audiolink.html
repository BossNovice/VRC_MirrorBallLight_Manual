音に反応させる

AudioLink連動

音に合わせて明るさ・サイズ・色を動かします。Materialごとに反応を変えることもできます。

準備

  1. VCCでAudioLinkを導入し、公式AudioLink Prefabをシーンへ配置します。
  2. AudioLink側へワールドの音源を接続します。
  3. Controllerの「AudioLinkを使用」をONにします。
  4. テストモードで見た目を作り、最後にテストモードをOFFにします。
  5. 「現在の設定をマテリアルへ反映・保存」を実行します。

用途別の反応帯域

値 目安 向いている演出
0 低音 キック、ベース、全体の明るさ
1 低中音 スネア下部、リズム
2 中高音 ボーカル、メロディ、色変化
3 高音 ハイハット、細かなきらめき
表示名 初期値 用途
明るさの反応帯域 0 Emission増幅
光点サイズの反応帯域 0 光点拡大
色変化の反応帯域 2 色相変化
アバターライトの反応帯域 0 AudioSource解析による実光Intensity
コード上には旧互換フィールド「反応する帯域（0：低音～3：高音）」が保持されていますが、Custom Inspectorでは表示されません。現在は用途別の3帯域を設定します。

反応量と安定化

表示名 初期値 効果
音による明るさの増加 2 / 0–10 音量ピーク時のEmission倍率。最終値は「明るさの上限」で制限されます。
音による光点サイズの増加 0.18 / 0–1 音に合わせた光点サイズ増加量です。
音による色変化の増加 0.35 / 0–2 帯域値による色相変化の量です。
音声反応の平滑化 0.65 / 0–1 高いほど急変を抑え、滑らかになります。
音声反応のしきい値 0.05 / 0–1 小さなノイズを無視する下限です。

履歴・伝播

AudioLink履歴モード 動作
全体を同時反応 現在値を全光点へ同時適用します。
上下へ伝播 縦位置に応じた履歴サンプルを読み、波が上下へ流れます。
回転方向へ伝播 球面の横方向に履歴差を作ります。
光点ごとにランダム セルごとに異なる履歴位置を使います。
AudioLink基本遅延（履歴サンプル） 0 / 0–124。全体の履歴読み取り開始位置です。
光点ごとの遅延差 24 / 0–124。モード1–3で位置ごとに広げる履歴幅です。

MaterialごとのAudioLink反応マスク

Controllerの共通AudioLink設定を保ったまま、壁・床・ガラスなどのMaterialごとに「どの部分を音へ反応させるか」と「どの模様で発光させるか」を分けられます。設定はControllerではなく、対象MaterialのInspectorで行います。

Material表示名効果
個別AudioLinkマスクを使用ONにすると、このMaterialだけAudioLink反応マスクを参照します。
AudioLink反応マスク白い部分は通常どおり音へ反応し、黒い部分はAudioLinkによる明るさ・サイズ・色変化を抑えます。灰色は中間です。
AudioLinkマスクの強さ0でマスクなし、1でTextureを完全適用します。
AudioLinkマスクを反転白黒の役割を反転します。
個別発光パターンを使用ONにすると、このMaterialの反射光へ固有の模様を乗算します。
発光パターンテクスチャRGBは発光色、Alphaは発光量として使われます。AlphaがないTextureではRGB輝度をマスクに使用します。
発光パターンの色／適用量／反転模様のHDR色、元の反射との混合量、白黒反転を設定します。
発光パターンのスクロール速度XとYでUVを時間移動します。0,0なら固定です。
発光パターンの音連動量この模様だけに追加するAudioLink明るさ倍率です。Controllerの共通増加量へ加算され、最終値は明るさ上限で制限されます。
例：壁Aは縦縞マスク、壁Bは市松模様、ガラスは円形グラデーションというように、同じControllerへ登録したまま別々の演出を設定できます。
ON/OFFを変更した後は、Unityメニューの Tools > MirrorBall Light > 診断・最適化 で「安全に自動修正」を実行してください。VRChatビルドへ必要なMaterial固有Keywordが確実に保存されます。

Material個別AudioLink・発光パターン

4種類のSurface Shader（通常／透明／LTCGI・VRCLightVolumes通常／同透明）で使用できます。これらはMaterial固有値であり、Controllerの「Shader Global共有を使用」がONでも上書きされません。

項目初期値効果
個別AudioLinkマスクを使用OFFMaterial固有の音声反応領域を有効化します。
AudioLink反応マスク白白＝反応、黒＝音による変化なし。TextureのTiling／Offsetも利用できます。
AudioLinkマスクの強さ10で無効、1で完全適用します。
AudioLinkマスクを反転OFF白黒を反転します。
個別発光パターンを使用OFF反射光へMaterial固有の模様・色を適用します。
発光パターンテクスチャ白RGBを発光色、AlphaまたはRGB輝度を発光マスクとして使用します。
発光パターンの色白Texture色へ乗算するHDR色です。
発光パターンの適用量10で元の反射、1でパターンを完全適用します。
発光パターンを反転OFF発光する場所と消える場所を反転します。
発光パターンのスクロール速度0, 0X／Y方向へUVを毎秒スクロールします。
発光パターンの音連動量0このMaterialだけAudioLink明滅を追加します。

透明Shaderでは個別発光パターンがEmissionだけでなく反射光部分のAlphaにも反映されるため、消灯箇所だけが透明になります。ガラス本体の基礎透明度には影響しません。

個別マスクと発光パターンはミラーボール反射部分だけへ適用されます。LTCGIやVRCLightVolumesから受ける環境照明そのものはマスクしません。

音源なしでテスト

「AudioLinkテストモード」をONにすると、Shaderへ固定の「テスト音量」（初期値0.5）を渡します。Unity Editorで反応量・上限・光点サイズを確認できます。アップロード前にはOFFへ戻してください。

テストモードがONのままだと、VRChat上でも固定入力が優先され、実際の音へ反応しません。

アバター実光のAudioLink連動

壁のShaderはAudioLinkテクスチャを参照しますが、Realtime Lightは「AudioLink入力AudioSource」をControllerがSpectrum解析します。AudioSource未指定時は実光の音連動が行われません。

アバター用ライトの音連動量 0.5 / 0–2。0で一定、値を上げるほど音量によるIntensity変化が増えます。
明るさの安全性 顔への強い点滅を避けるため0.2–0.6程度から調整します。
