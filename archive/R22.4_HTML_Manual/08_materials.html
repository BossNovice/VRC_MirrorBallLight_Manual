通常の壁・床

Material項目 効果
壁・床の基本テクスチャ 元のAlbedo／Base Mapです。
ノーマルマップ 凹凸情報。Texture Import TypeをNormal mapにします。
ノーマルマップの強さ 0で無効、1で標準、2で強調します。
壁・床の基本色 Textureへ乗算される色です。
反射光の基本色 光点Emissionの基準HDR色です。Controllerへ登録している場合は「基本色」から更新されます。
金属感 0は非金属、1は金属寄りです。
滑らかさ 高いほど環境反射が鋭くなります。

反射光以下の演出項目はControllerと同名です。Controllerへ登録している場合はController側を正として設定します。

ガラス・透明／半透明オブジェクト

Material項目 効果
透明度 素材全体のAlpha。Controllerの「透過面の本体透明度」で更新されます。
反射光部分の不透明度 光点部分の見え方。Controllerの「透過面の光点不透明度」で更新されます。
透過マスクの回転追従 透明マスクを投影回転へ追従させます。
深度書き込み 通常OFF。重なり順問題を改善する場合だけONを試しますが、他の透明物を隠す場合があります。
面の描画 Backは表面、Frontは裏面、Offは両面を描画します。ガラス板を両側から見る場合はOffを検討します。
透明Shaderは描画順の制約があります。Particle、別のガラス、鏡などと重なる場合はRender QueueとZWriteをシーンごとに確認してください。

MirrorBallFacetBody

分類 項目 効果
基本 鏡片の基本色／金属感／滑らかさ 本体の基礎PBR表現です。暗所では基本色を完全な黒にしないでください。
Facet Layout 横方向の鏡片数／縦方向の鏡片数 鏡片の密度です。初期値48×24。
Facet Layout 鏡片の形状 Square等の鏡片輪郭を選びます。
Facet Layout 目地の太さ／目地境界のぼかし／目地の色 鏡片の境界を作ります。太すぎると球全体が暗くなります。
Facet Normal 鏡片面の平面化 球の連続法線を鏡片ごとの平面へ近づけます。初期0.88。
Facet Normal 鏡片ごとの傾き 法線をランダムにずらし反射方向を散らします。
Facet Normal 鏡片ごとの色むら 均一さを崩します。
暗所対策 暗所での最低表示明るさ 環境光が弱い場所でも真っ黒になるのを防ぎます。初期0.08。
反射 反射Cubemap（任意）／反射・スパークル色／Cubemap反射の強さ 任意Cubemapの反射と、反射・きらめきのHDR色を調整します。
スパークル スパークルの強さ／スパークルの鋭さ／スパークルの明滅量／スパークルの明滅速度 視線と鏡片法線が合う箇所のきらめきの強度、範囲、時間変化を調整します。
安全 発光の上限 本体Emissionの最大値です。初期8。
AudioLink AudioLinkを使用／反応する帯域（0低音～3高音）／音によるスパークル増加／音声反応のしきい値／AudioLinkテストモード／テスト音量 本体スパークルを指定帯域へ反応させます。テストモードは公開前にOFFにします。
本体が黒い場合は、基本色、暗所での最低表示明るさ、目地の太さ、Cubemap、Controllerの電源・本体明るさ倍率の順で確認します。

Controller連動とMaterial直編集

  • Controllerの対象Materialへ登録したSurfaceは、色・明るさ・AudioLink・光点・Cookie・距離・Texture参照・Keywordを更新されます。
  • Base Texture、Normal Map、基本色、金属感、滑らかさ等の素材固有値はMaterial側で設定します。
  • 本体は「Controllerの色・電源・AudioLink設定と連動」がONの時だけ演出値が同期します。
  • Edit Mode変更をAssetへ残すには「現在の設定をマテリアルへ反映・保存」を押します。
