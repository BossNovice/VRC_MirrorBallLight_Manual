MirrorBallLightController
導入・設定マニュアル

Unity／VRChat World向けミラーボール演出の導入から、通常面・ガラス面、AudioLink、ライブプリセット、同期スイッチまでをまとめた単一ページ版です。

1. 動作環境

必須

  • VRChat Creator Companionで作成したWorldプロジェクト
  • VRCSDK Worlds
  • UdonSharp
  • VRChat指定のUnity 2022.3系

描画環境

  • Built-in Render Pipeline
  • PC向け
  • Quest／Android非対応

任意連携

  • AudioLink
  • VRC Light Volumes 2.x
  • LTCGI API v2
VRCLightVolumes／LTCGI連携Shaderを使う場合は、対応パッケージを先にVCC／VPMから導入してください。通常版Shaderだけなら不要です。

2. 導入

  1. R17 ZIPを展開します。
  2. ZIP内の Assets/MirrorBallLight フォルダを、Unityプロジェクトの Assets 直下へコピーします。
  3. Unityへ戻り、右下のコンパイル表示が消えるまで待ちます。
  4. Tools > MirrorBall Light > Repair UdonSharp Program Asset を1回実行します。ControllerとPresetのProgram Assetが確認・作成されます。
  5. Consoleに赤いコンパイルエラーがないことを確認します。
Assets/ └─ MirrorBallLight/ ├─ Scripts/ │ ├─ MirrorBallLightController.cs │ └─ MirrorBallLightPreset.cs ├─ Editor/ ├─ Shaders/ └─ Documentation/
同名フォルダがすでにある場合は、古い内容へ重ねずバックアップ後にR17のフォルダへ置き換えてください。異なる世代の同名スクリプトを同時に置かないでください。

3. 基本セットアップ

  1. シーンにミラーボール本体を配置します。回転させるTransformを明確に分けておくと設定しやすくなります。
  2. 空のGameObjectを作成し、MirrorBallLightController を追加します。
  3. Controllerの ミラーボール本体 に回転対象のTransformを割り当てます。
  4. 必要なら 照射スポットライト にLightを割り当てます。未設定時はミラーボール位置と下方向を基準にします。
  5. 壁・床・天井・ガラスへ対応Materialを割り当てます。
  6. 対象マテリアルをシーンから自動検出 を押します。
  7. Inspector最下部の 現在の設定をマテリアルへ反映・保存 を押します。
Target MaterialsにはProjectウィンドウ内のMaterialアセットを使用してください。Play中に生成されたMaterialやTextureはVRChatビルドへ保存されません。

4. MaterialとShader

用途Shader補足
通常の壁・床・天井MirrorBallLight/MirrorBallSurfaceAutoOpaque。標準構成
ガラス・半透明面MirrorBallLight/MirrorBallSurfaceAutoTransparent透明度と光点不透明度を分離
通常面＋照明連携MirrorBallLight/Integrations/MirrorBallSurfaceAuto (VRCLightVolumes + LTCGI)両パッケージ導入時のみ
透過面＋照明連携MirrorBallLight/Integrations/MirrorBallSurfaceAutoTransparent (VRCLightVolumes + LTCGI)PC向け高機能版

形状に画像を使う場合は 光点の形状＝テクスチャ を選び、Project内のTextureアセットを設定します。白／不透明部分が発光し、黒／透明部分が消えます。推奨は正方形PNG、Wrap Mode＝Clamp、Mip Maps＝OFFです。

ノーマルマップ（R17.1以降）

  1. 画像のTexture Typeを Normal map に設定してApplyします。
  2. 各Materialの ノーマルマップ へ割り当てます。
  3. ノーマルマップの強さ を調整します。0＝平坦、1＝標準、2＝強調です。

通常面、透過面、連携版の全Shaderで使用できます。凹凸はStandard Surface、面方向補正、VRCLightVolumesおよびLTCGIの法線評価へ反映されます。ガラスでは強さ0.1～0.5程度からの調整を推奨します。

3. アバターへの実光反映

壁のEmissionとは別に、Realtime Point LightまたはVRCLightVolumes用オブジェクトを電源・AudioLinkへ連動します。Realtime Lightは1灯・影なし・Playerレイヤー限定を推奨します。

4. 回転・反射・カラー

反射

反射光の明るさが基本強度、明るさの上限がAudioLink反応後を含むBloom暴走防止値です。

表示面別

通常面と透過面の光点倍率、ガラス本体と光点の不透明度を個別設定できます。

距離フェード

開始距離までは最大強度、開始～終了の間で滑らかに消えます。終了は開始より大きくします。

カラー

ランダム色、彩度、色相速度、色別明滅を調整します。

5. AudioLink連動

明るさ・光点サイズ・色変化で別々の帯域を指定できます。詳細は後述します。

6. 光点・形状・ランダム点灯・負荷

タイル数、サイズ、ぼかし、縦横比、形状、点灯割合、切替速度と更新頻度をまとめています。

7. VRCLightVolumes・LTCGI連携

Target Materials内の連携対応Materialだけを一括ON／OFFし、Materialアセットへ保存します。

6. ライブプリセット

ライブプリセットは固定個数ではありません。Controllerの子に MirrorBallLightPreset を必要数追加し、一覧へ登録する拡張方式です。

プリセットを作る

  1. 2. ライブプリセット を開き、ライブプリセットを使用 をONにします。
  2. Controllerを好みの演出へ調整します。
  3. 新しいプリセットを追加 を押します。現在値を複製した子GameObjectが作られます。
  4. 作成された子を選択し、プリセット名 と各演出値を編集します。
  5. 必要な数だけ追加します。一覧がずれたときは 一覧を子から自動検出 を押します。

確認・保存

操作用途
選択プリセット番号0から始まる一覧番号
選択番号をプレビュー適用指定プリセットをEditor上でControllerとMaterialへ反映
現在値を選択プリセットへ保存Controllerで調整した値を指定プリセットへ上書き
開始時に選択中プリセットを適用World開始時に同期済み／初期番号を自動適用

切替方法

Udonスイッチやボタンから次のCustom Eventを送ります。

NextPreset

次へ進み、末尾から先頭へ戻ります。

PreviousPreset

前へ戻り、先頭から末尾へ移動します。

ReloadCurrentPreset

現在の番号を再適用します。

ApplySelectedPreset

presetSelectionIndex の番号を適用します。

グローバル同期時：全プレイヤーでプリセット一覧の並びと数が同じ必要があります。同期されるのは番号です。プリセットGameObjectを実行中に増減する機能ではありません。

プリセットには回転速度、色・明るさ、通常／透過面、AudioLink帯域と反応量、光点形状、ランダム点灯、距離フェードが保存されます。Transform、Material一覧、Light参照、電源設定などのシーン基盤は切り替えません。

7. AudioLink設定

  1. VCCからAudioLinkをプロジェクトへ追加します。
  2. 公式Prefab／Controllerをシーンに配置し、音源を設定します。
  3. MirrorBall Controllerの AudioLinkを使用 をONにします。
  4. 各用途の帯域と増加量を調整します。
  5. 現在の設定をマテリアルへ反映・保存 を押します。
帯域目安おすすめ用途
0低音明るさ、サイズ、キック反応
1低中音サイズ、全体の脈動
2中高音色変化
3高音細かなきらめき

開始例：明るさ 0サイズ 0または1色 2平滑化 0.65しきい値 0.05

壁側ShaderはAudioLinkのGPUテクスチャを直接参照します。アバター用Realtime Lightも音連動させる場合は、AudioLink入力と同じAudioSourceを AudioLink入力AudioSource へ割り当てます。

8. ガラス・透明・半透明面

透過面にはTransparent版Shaderを使用します。Controllerは _Opacity プロパティを持つMaterialを透過面として自動判定します。

設定効果推奨開始値
透過面の光点明るさ光点Emissionの強度倍率1.0
透過面の本体透明度ガラス面全体の見え方0.15～0.35
透過面の光点不透明度光点部分の輪郭の強さ0.7～1.0
透過マスクの回転追従透明度模様が回転光点へ追従する割合1.0
既存の高機能ガラスShaderを維持したい場合は、同じ位置へ少し拡大した表示専用メッシュを重ね、そのMaterialだけMirrorBall Transparent版にする方法があります。透明面同士の交差では描画順の違いが出る可能性があります。

9. 電源・ローカル／グローバル同期

Controller GameObjectにColliderを追加し、このオブジェクトをクリックして切替 をONにするとInteractで電源を切り替えられます。別Udonからは TurnOn、TurnOff、TogglePower を送ります。

範囲動作
ローカル（自分だけ）操作したプレイヤーの画面だけで切替。通信なし
グローバル（全員に同期）所有権を取得しManual同期。途中参加者にも状態を反映

ライブプリセットには電源とは独立した プリセットの動作範囲 があります。電源は全員、プリセット選択は自分だけ、という設定も可能です。

10. VRCLightVolumes・LTCGI

  1. 対象パッケージをVCC／VPMから先に導入します。
  2. シーンのVolume／LTCGI Controllerを公式手順で設定・Bake／Updateします。
  3. Materialを連携版Shaderへ変更します。
  4. ControllerでMaterialを自動検出します。
  5. VRCLightVolumes・LTCGI一括設定 の すべてON を押します。
連携版は両パッケージのincludeを参照します。どちらかが未導入の場合、連携版Shaderはコンパイルできません。その場合は通常版Shaderを使用してください。

11. 負荷と画質の調整

設定負荷優先滑らかさ優先
マテリアル更新頻度15～20回/秒30～60回/秒
横／縦の光点数少なめ演出に必要な範囲
Realtime Light1灯、Shadows=Noneを推奨
面の向き補正OFF必要な面だけON

AudioLink、色変化、ランダム点灯はGPU側で進むため、静止中にControllerのMaterial転送が省略されても演出は継続します。オプション切替後は反映・保存ボタンを押し、使用中ShaderキーワードをMaterialへ保存してください。

12. VRChatアップロード前チェック

  • Consoleに赤いコンパイルエラーがない
  • Mirror Ball Transformが設定されている
  • Target Materialsに必要なMaterialが登録されている
  • 形状TextureがProject内のアセットになっている
  • ライブプリセット一覧にnullがなく、並び順が意図どおり
  • グローバル同期をClientSimまたは複数クライアントで確認した
  • 設定変更後に「現在の設定をマテリアルへ反映・保存」を押した
  • 連携版利用時はVRCLightVolumesとLTCGIが導入済み
  • Bloomが白飛びする場合は「明るさの上限」を下げた
